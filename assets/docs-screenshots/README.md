# Screenshots for the guide

Drop a PNG in here under the name a page asks for and say so, and the
placeholder in that page becomes the picture.

Every request is a blockquote beginning **Screenshot wanted**. What is still
outstanding:

    grep -rn "Screenshot wanted" docs/guide

## What the guide asks for

| File | What it should show | Page |
| --- | --- | --- |
| `install-addons-list.png` | The character select addon list with WiggleUI ticked. | [install](../../docs/guide/install.md) |
| `setup-mode.png` | The mode card page of the first login, with the three previews drawn. | [first login](../../docs/guide/first-run.md) |
| `theme-exploration.png` | The whole screen under exploration, mid fight. | [look](../../docs/guide/look.md) |
| `theme-immersive.png` | The same fight under immersive, so the pair reads as one change. | [look](../../docs/guide/look.md) |
| `palettes.png` | One window in four palettes, parchment among them so the torn edge shows. | [look](../../docs/guide/look.md) |
| `charge-marker.png` | The marker over the mob the charge would hit, with the button lit. | [fighting](../../docs/guide/fighting.md) |
| `actionbars.png` | Two bars at different row counts and backgrounds, one hidden behind shift. | [action bars](../../docs/guide/bars.md) |
| `frames-player-target.png` | Player and target blocks with a heal slice on the gauge and a few auras. | [frames](../../docs/guide/frames.md) |
| `character-stats.png` | The character sheet stats page with the miss rows. | [windows](../../docs/guide/windows.md) |
| `meters.png` | Both meter panes mid fight, with a threat number close to a pull. | [feeds and meters](../../docs/guide/feeds.md) |
| `minimap.png` | The square minimap with the button corral open. | [the screen](../../docs/guide/screen.md) |
| `bags-vendor.png` | The bag window at a vendor, with the sell and repair row showing. | [chores](../../docs/guide/chores.md) |

Crop to the thing being shown, apart from the three that are about the whole
screen: the two theme shots and the palette strip.

More than the list are welcome. A window the guide describes in a paragraph and
does not show is a window somebody has to install the addon to see.
